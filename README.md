# Rajesh Ramdas — Fine Art & Luxury Wedding Photography

An ultra-luxury fine-art and wedding photography portfolio website for **Sri T. Rajesh Ramdas**, based in Kakinada, Andhra Pradesh, India.

---

## 🏛️ Brand & Concept

- **Display Name**: RAJESH RAMDAS
- **Role**: Fine Art & Luxury Wedding Photographer · Visual Storyteller
- **Location**: Kakinada, Andhra Pradesh, India
- **Philosophy**: *"The moment passes. The frame remains."* · *"The moment before it disappears."*

---

## 💎 Features

- **Artisan Vector Monogram Logo**: Bespoke intertwining "RR" seal in gold and alabaster.
- **High-Fashion Typography**: `Cinzel`, `Cormorant Garamond`, and `Plus Jakarta Sans` Google Fonts.
- **Cinematic Hero Carousel**: Auto-advancing multi-slide showcase with manual progress indicators and title crossfades.
- **Curated Galleries**: Real curated Andhra landscapes, macro dew reflections, and royal Indian wedding & wildlife collections.
- **Interactive Filterable Portfolio**: Category tabs (`All`, `Weddings`, `Portraits`, `Wildlife`, `Nature`, `Travel`) with instant Lightbox zoom.
- **Client Love Stories**: Romantic couple reviews and venue accolades.
- **Press Recognition**: Featured badges for WeddingSutra, WedMeGood, Fearless Photographers, and Shutterstock.
- **World Photography Day Tribute**: Atmospheric darkroom tribute experience for Annayya (*"For the photographer"* in footer).
- **Consultation Suite**: Direct commission inquiry form with Web Share API and clipboard copy fallbacks.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router, Static Site Generation)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Typography**: `next/font/google` (`Cinzel`, `Cormorant_Garamond`, `Plus_Jakarta_Sans`)

---

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+

### Installation & Run

```bash
# Install dependencies
npm install

# Run development server on port 3001
npm run dev

# Build for production
npm run build

# Run production build
npm start
```

---

## 🌐 Deployment to Vercel

1. Push this repository to your GitHub account (`rajesh-ramdas-photography`).
2. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New..."** > **"Project"**.
3. Select and import the `rajesh-ramdas-photography` repository.
4. Framework Preset will auto-detect as **Next.js**.
5. Click **"Deploy"**.
